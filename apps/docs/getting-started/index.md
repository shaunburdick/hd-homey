# Getting Started

Welcome to HD Homey! This guide will help you set up and start streaming from your HDHomeRun devices.

## Quick Overview

HD Homey is a Next.js-based proxy application that enables secure remote access to live TV streams from your HDHomeRun network tuners. Whether you're at home or on the go, you can watch live TV through a modern web interface or external media players.

## What You'll Need

Before getting started, make sure you have:

- **HDHomeRun Device**: A network-connected HDHomeRun tuner on your local network
- **Docker** (recommended): For the easiest deployment method
- **Or Node.js 20+**: If you prefer running from source
- **Network Access**: Ability to expose port 3000 or configure reverse proxy

## What's Next?

After installation, you'll want to:

1. **Add Your Tuners**: Configure your HDHomeRun devices in the Tuners page
2. **Scan Channels**: Discover available channels from your tuners
3. **Create Users**: Set up viewer accounts for family or friends
4. **Configure Streaming**: Set transcoding preferences and stream security options
