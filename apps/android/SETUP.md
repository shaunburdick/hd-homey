# Android Studio Setup Guide (macOS)

Complete step-by-step instructions for setting up the HD Homey Android TV app development environment on macOS.

## Prerequisites

- macOS 11 (Big Sur) or later
- At least 8GB RAM (16GB recommended for emulator)
- 20GB free disk space
- Git installed
- Internet connection

## Step 1: Install Android Studio

### Option A: Download from Website (Recommended)

1. Visit [https://developer.android.com/studio](https://developer.android.com/studio)
2. Click **Download Android Studio**
3. Accept the terms and download the `.dmg` file
4. Open the downloaded `.dmg` file
5. Drag **Android Studio.app** to your **Applications** folder
6. Open **Android Studio** from Applications
7. Follow the setup wizard:
   - Choose **Standard** installation
   - Select theme (your preference)
   - Click **Finish** to download SDK components

### Option B: Install via Homebrew

```bash
brew install --cask android-studio
open -a "Android Studio"
```

## Step 2: Initial Android Studio Configuration

### SDK Setup

1. When Android Studio opens, go to **Android Studio → Preferences** (or **⌘,**)
2. Navigate to **Appearance & Behavior → System Settings → Android SDK**
3. In the **SDK Platforms** tab, install:
   - ✅ **Android 14.0 (UpsideDownCake)** - API Level 34
   - ✅ **Android 13.0 (Tiramisu)** - API Level 33
   - ✅ **Android 12.0 (S)** - API Level 31 *(minimum for TV)*
4. In the **SDK Tools** tab, ensure these are installed:
   - ✅ Android SDK Build-Tools
   - ✅ Android SDK Command-line Tools
   - ✅ Android Emulator
   - ✅ Android SDK Platform-Tools
   - ✅ Google Play services
5. Click **Apply** to download and install

### Note SDK Location

The SDK path is typically:
```
/Users/YOUR_USERNAME/Library/Android/sdk
```

You'll need this for `local.properties`.

## Step 3: Install Java Development Kit (JDK)

Android Studio typically includes a JDK, but you may want to install one system-wide.

### Check Current Java Version

```bash
java -version
```

### Install JDK 17 (Recommended)

```bash
# Via Homebrew:
brew install openjdk@17

# Add to PATH (add to ~/.zshrc or ~/.bash_profile):
echo 'export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# Verify:
java -version
```

## Step 4: Clone HD Homey Repository

```bash
# Navigate to your projects directory:
cd ~/Projects  # Or wherever you keep projects

# Clone the repository:
git clone https://github.com/shaunburdick/hd-homey.git
cd hd-homey

# Checkout the Android development branch:
git checkout 013-android-app  # Or 'main' after Phase 1 is merged
```

## Step 5: Open Android Project in Android Studio

### Method A: From Android Studio

1. Open **Android Studio**
2. Click **Open**
3. Navigate to: `~/Projects/hd-homey/apps/android`
4. Click **Open**
5. Wait for Gradle sync to complete (may take several minutes on first run)

### Method B: From Terminal

```bash
cd ~/Projects/hd-homey
open -a "Android Studio" apps/android
```

### First-Time Project Setup

When opening the project for the first time, Android Studio will:

1. **Detect missing files** - It will create `local.properties` automatically
2. **Download Gradle** - May take 5-10 minutes depending on connection
3. **Sync Gradle dependencies** - Downloads all project dependencies
4. **Index files** - Builds code completion database

**⏳ Be patient** - This can take 10-15 minutes on first launch.

## Step 6: Configure local.properties

After Android Studio creates `apps/android/local.properties`, edit it:

```properties
# This file was automatically generated by Android Studio.
sdk.dir=/Users/YOUR_USERNAME/Library/Android/sdk

# Add these custom properties:

# Backend API URL for development
# Use your Mac's local IP address (not localhost)
# Find with: ipconfig getifaddr en0
backend.url=http://192.168.1.XXX:3000

# Or use ngrok/tunneling for remote testing:
# backend.url=https://your-tunnel.ngrok-free.app
```

### Find Your Mac's IP Address

```bash
# Wi-Fi interface:
ipconfig getifaddr en0

# Ethernet interface:
ipconfig getifaddr en1

# Or use System Preferences:
# System Preferences → Network → Select active connection → IP address shown
```

**Important**: The emulator cannot use `localhost` or `127.0.0.1` to reach your Mac. You must use your Mac's actual IP address on the network.

## Step 7: Create Android TV Emulator

### Create TV Device

1. In Android Studio, click **Tools → Device Manager** (or click the device icon in toolbar)
2. Click **Create Device** button
3. In the **Category** list, select **TV**
4. Select a device definition:
   - **Recommended**: **Android TV (1080p)** - Standard TV
   - Alternative: **Android TV (4K)** - 4K TV (requires more RAM)
5. Click **Next**

### Select System Image

1. Click the **x86 Images** tab (faster on Intel Macs)
2. Select **API Level 31** or higher (Android 12.0+)
   - Look for **Google TV** variants if available
3. Click **Download** next to the system image (if not already downloaded)
4. Wait for download to complete
5. Click **Next**

### Configure AVD

1. **AVD Name**: `HD_Homey_TV_1080p`
2. **Startup orientation**: Landscape
3. **Advanced Settings** (click "Show Advanced Settings"):
   - **RAM**: 2048 MB minimum (4096 MB recommended)
   - **Internal Storage**: 2048 MB
   - **SD card**: 512 MB (optional)
   - **Emulated Performance**:
     - Graphics: **Hardware - GLES 2.0** (or **Automatic**)
     - Boot option: **Cold boot**
4. Click **Finish**

### Launch Emulator

1. In Device Manager, click the **▶️ Play** button next to your TV device
2. Wait for emulator to boot (1-2 minutes on first launch)
3. You should see the Android TV home screen

**Tip**: Keep the emulator running between development sessions to avoid slow boot times.

## Step 8: Verify Backend API

Before running the Android app, ensure the HD Homey backend is running and accessible.

### Start Backend Server

Open a terminal and start the backend:

```bash
# If backend is on same Mac:
cd ~/Projects/hd-homey
npm install  # First time only
npm run dev  # Starts on 0.0.0.0:3000

# If backend is on WSL2/another machine:
# SSH or access that machine and start the backend there
```

### Test API Connectivity

From your Mac terminal (not emulator):

```bash
# Replace with your actual backend URL:
curl http://192.168.1.XXX:3000/api/health

# Expected response:
# {"status":"ok","timestamp":"2024-12-13T...","version":"1.0.0-beta.6",...}
```

### Test from Emulator

1. Launch your TV emulator
2. Open emulator's browser (if available) or use `adb`:

```bash
# From Mac terminal:
adb shell

# Inside emulator shell:
curl http://192.168.1.XXX:3000/api/health
# Or:
wget -qO- http://192.168.1.XXX:3000/api/health

# Exit shell:
exit
```

If you get a response, the connection works!

## Step 9: Build and Run the App

### Run from Android Studio

1. In Android Studio, select your TV emulator from the device dropdown (top toolbar)
2. Click the green **Run** button (▶️) or press **⌃R** (Control+R)
3. Wait for Gradle build to complete
4. App will install and launch on the emulator

### Run from Command Line

```bash
cd ~/Projects/hd-homey/apps/android

# Build and install debug APK:
./gradlew installDebug

# Launch the app:
adb shell am start -n com.hdhomey.tv/.MainActivity
```

## Step 10: Enable Developer Features (Optional but Recommended)

### Enable ADB over Network (for physical devices)

If you have a physical Android TV device:

1. On Android TV, go to **Settings → Device Preferences → About**
2. Click **Build** 7 times to enable Developer Options
3. Go back to **Device Preferences → Developer options**
4. Enable **USB debugging**
5. Enable **Network debugging**
6. Note the IP address shown

From Mac:
```bash
adb connect 192.168.1.XXX:5555  # Replace with TV's IP
adb devices  # Verify connection
```

### Install scrcpy for Screen Mirroring (Optional)

```bash
brew install scrcpy

# Mirror Android TV to your Mac screen:
scrcpy
```

## Troubleshooting

### Issue: "SDK location not found"

**Solution**: Ensure `local.properties` exists and has the correct SDK path:

```bash
cd ~/Projects/hd-homey/apps/android
cat local.properties

# Should show:
# sdk.dir=/Users/YOUR_USERNAME/Library/Android/sdk
```

If missing, create it:
```bash
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
```

### Issue: "Cannot connect to backend API"

**Symptoms**:
- App shows "Network Error"
- Pairing code generation fails

**Solution**:
1. Verify backend is running: `curl http://YOUR_IP:3000/api/health`
2. Check `backend.url` in `local.properties` is your Mac's IP, not `localhost`
3. Ensure firewall allows port 3000:
   - **System Preferences → Security & Privacy → Firewall → Firewall Options**
   - Add exception for port 3000 or Node.js
4. Try backend on `0.0.0.0:3000` instead of `localhost:3000`

### Issue: Emulator is slow

**Solution**:
1. **Close other apps** - Free up RAM
2. **Reduce emulator RAM** - Try 2048 MB instead of 4096 MB
3. **Disable animations**:
   - In emulator: **Settings → Developer options**
   - Set all animation scales to **0.5x** or **Animation off**
4. **Use x86 images** - Faster than ARM emulation
5. **Enable hardware acceleration**:
   - Intel Macs: Install HAXM
   - Apple Silicon: Use Hypervisor.framework (automatic)
6. **Consider physical device** - Always faster than emulator

### Issue: Gradle sync failed

**Solution**:
1. **Check internet connection** - Gradle needs to download dependencies
2. **Invalidate caches**:
   - **File → Invalidate Caches → Invalidate and Restart**
3. **Clean build**:
   ```bash
   cd apps/android
   ./gradlew clean build
   ```
4. **Update Gradle wrapper**:
   ```bash
   ./gradlew wrapper --gradle-version=8.4
   ```

### Issue: "Unable to locate adb"

**Solution**:
Add Android SDK platform-tools to PATH:

```bash
# Add to ~/.zshrc or ~/.bash_profile:
echo 'export PATH="$HOME/Library/Android/sdk/platform-tools:$PATH"' >> ~/.zshrc
source ~/.zshrc

# Verify:
which adb
adb version
```
